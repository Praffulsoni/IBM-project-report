# IBM Applied Data Science Capstone — SpaceX Falcon 9 Landing Prediction

This repository contains the project-report materials for the IBM Applied Data Science Capstone.

## Repository contents

- `01_SpaceX_API_Data_Collection.ipynb` — SpaceX REST API collection and normalization
- `02_SpaceX_Web_Scraping.ipynb` — Wikipedia launch-table scraping
- `03_SpaceX_Data_Wrangling.ipynb` — cleaning, target construction and feature preparation
- `04_SpaceX_EDA_Visualization.ipynb` — exploratory data analysis and visualizations
- `05_SpaceX_SQL_Analysis.ipynb` — SQL queries and analytical summaries
- `06_SpaceX_Folium_Map.ipynb` — interactive geographic analysis
- `07_SpaceX_Predictive_Analysis.ipynb` — classification, model comparison and evaluation
- `08_SpaceX_Plotly_Dash.py` — Plotly Dash dashboard application
- `Data_Science_Capstone_Report.md` — presentation/report content and findings

## Objective
Predict whether a Falcon 9 first stage will successfully land using historical launch characteristics including flight history, payload, orbit and launch site.

## Workflow
REST API / web scraping → data wrangling → EDA + SQL → Folium + Plotly Dash → classification → model evaluation.
